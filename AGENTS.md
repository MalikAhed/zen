# Website Working Agreement

- Build the website in fast, simple edit-and-feedback loops.
- Start by mapping the general page layout with empty grey boxes only.
- Do not add fonts, finished components, images, decorative styling, or content until the layout is approved.
- Keep each change small and easy to review.
- Avoid unnecessary abstractions, dependencies, and over-engineering.
- Run the local development server while working whenever the project has one configured.
